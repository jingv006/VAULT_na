# 使用说明

## 本机启动

建议目录结构：

```text
GPT-VAULT/
├── vault-workbench/          # 本项目源码
└── 261021_VAULT_USSA_S/      # 自己准备的原始模型库
```

Mac 双击项目内 `启动工作台.command`，或运行 `python3 server.py --port 8766 --open`。本机服务只监听 127.0.0.1，模型转换和打包在本机完成。Mac 入口会复用已有服务，端口占用时选择其他空闲端口。

基础网页和 STL ZIP 打包使用 Python 3.9+ 标准库。真实三维和 3MF 转换需要 NumPy；跨系统或 Python 版本时，三维网格简化需使用对应环境的 `fast-simplification==0.1.12`。仓库自带的简化扩展适用于原 Mac / Python 3.9 环境。依赖可用 `python3 -m pip install numpy fast-simplification==0.1.12` 安装。

## 浏览器选择模型目录

静态网页可独立显示二维视图、配方和已保存的估算数据。点击“选择本地模型目录”，外层文件夹可任意命名，**内部目录结构必须保留**；读取在浏览器本地进行，不上传 STL。浏览器目录模式支持 STL 打包；真实三维和整合 3MF 需要本机服务。

## 三个工作区

- **尺寸总览**：选择型号，核对文件和数量；切换顶盖、网格底板、齿条与配色，下载单套预分色 3MF。
- **自由堆叠**：拖入模块、插入层间、查看支撑提示，保存/导入方案。S＋S 组合需有 L 底座，S＋M 需有 XL 底座。组合三维只加载外观零件。
- **抽屉隔板排布**：选择抽屉与隔板规格，拖动排布；按 R 旋转、Delete 删除，下载清单与对应官方模型。

## 导出与用量

“合并同名模型”每种 STL 保留一份，`print-N` 表示该 STL 的打印份数。“按模块输出整合 3MF”按型号、有效顶盖和配件配置归并，一份工程内保留一套零件，`print-N.3mf` 表示整份工程打印 N 套。被上层覆盖的抽屉不重复计顶盖；备用件另附 STL。手动修改零件数量后，使用第一项导出，或恢复配方再生成完整 3MF。

导出 3MF 使用与尺寸总览同步的自定义配色；随机浅色仅用于预览。工程未切片，不包含 G-code。用量按 H2D / 0.4 mm / 0.20 mm / 15% 填充 / 2 层墙的已有切片记录累计；合盘、转向、支撑与换机后会变化。打印机适配逐件检查 STL，而非检查整组柜子的外形。

名义尺寸用于拼接节距；闭合装配外尺寸包含当前外露顶盖及凸起，为预览估算。内腔参考不扣除局部筋位、圆角和机构。缺失尺寸显示待校验，不能作为保证可容纳物体的尺寸。

## 版本发布

双击 `上传到GitHub.command`，或运行 `python3 tools/publish_github.py --message "本次更新说明"`。脚本依据远程 main 的已发布版本递增 V1.x，自动同步三个页面、README、CHANGELOG、RELEASES.json 和带时间戳的 VERSION.json。无改动不递增，失败重试保留同一版本及时间，不强制覆盖远程提交。
